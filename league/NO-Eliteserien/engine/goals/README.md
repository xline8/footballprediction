# G-NO goals engine

Reads `../../data/no_matches.csv`; development loads 2021–2024, with 2021 warm-up and 2022–2024 scored. Arms are `gate_zero`, `shr`, and `x3`; primary line is OU 2.5 and the presentation-only 1H share is 0.439.

Run from this directory: `python3 run_g_no.py dev`. Outputs are `results_dev.json` and `results_dev.csv`. Virgin commands exist for the coordinator but were not run here.
