## GATE LEGS

Dev gate — pooled dev LL@18.5 beats BOTH baselines (league base rate; naive trailing-10), else the arm is dead, no virgin read. Virgin legs — (i) LL@18.5 ≤ Gate Zero's (arm A's) AND ≤ best baseline's (arm A: ≤ best baseline's); (ii) calibration |actual − mean P(over 18.5)| ≤ 1.0pp, SE reported, breach within 1 SE = PROVISIONAL PASS; (iii) dev per-season sign check for both-pass (variant dev LL@18.5 ≤ arm A's in ≥2 of 3 dev seasons). Both-pass: all passing → lowest pooled virgin LL ships; one → ships; none → FAIL.

Mechanical reading: an arm passes iff it survives the dev gate AND passes virgin legs (i)–(ii) (PROVISIONAL counts, recorded as such) AND, for variants, leg (iii). Ties → simpler arm (A before B before C). Arm A dev failure ⇒ variants moot, FAIL, virgin NOT read.
