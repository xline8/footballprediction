# Pre-registration — T-UY (UY-LigaAUF total shots): NOT BUILT

Frozen: 2026-11-10, before any fitting. Design authority:
`analysis/MODEL_DESIGN.md` (T-UY); evidence EDA F1/F6.

T-UY is **not built**, by feasibility, recorded here so the absence
is an auditable decision and not an omission:

- The total-shots target exists in NO season under any source. The
  stats feed is absent in every season (0/1,717 matches with
  `content.stats.Periods`, 0 stats keys in any raw JSON, 0 period
  splits in 2021–2026). There is no `total_shots` key anywhere, no
  shotmap anywhere (0/1,717), and no event-derived shots substitute.
- Trait reliability is not measurable on dev (split-half r null,
  n = 0 teams), no 1H share is computable on dev, and no line can
  be selected. There is no dev season, no warm-up season, and no
  scored dev window at all. This is the FI total-shots case in its
  strongest form: not a definition break within a dev window, but
  the complete absence of a dev window.
- No arm, window, or line is therefore frozen, nothing is fitted,
  and the virgin is not read for total shots. The frozen split is
  NOT moved to manufacture a dev window. If future seasons add a
  dev total-shots target, T-UY can be pre-registered fresh — it may
  not be rescued inside this prereg.

Verdict: `reports/T_UY_VERDICT.md` (not-buildable).
