# C-QASD engine

Gate Zero (X9) uses the frozen corners constants and carries `big_chance`
as a zero covariate because it is 0/0 in this league. It loads the 38-row
2024/2025 stats era, scores 2025/2026 rounds 8–14, and updates state only
after each date. Run `python3 run_c_qasd.py dev`; virgin is explicit-only.
