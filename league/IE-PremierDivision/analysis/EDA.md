# Phase 3 — EDA: IE-PremierDivision

All reported values are generated by `eda_compute.py` and stored in
`eda_numbers.json`. Estimates use 2021–2025 unless a narrower dev window is
explicitly stated; 2026 contributes only its coverage inventory.

## Levels and agreement

The `per_season` object records goals, SOT, corners, total shots, stats and
event yellows, reds, xG, coverage, and dates. The event target is higher than
the stats total in the artefact comparison: exact agreement is recorded in
`yellows_stats_vs_events` for matches with stats yellows.

## Reliability

`reliability` reports split-half r for and against goals, SOT, corners,
shots, event yellows, touches, big chances, and possession. Referee
reliability is separately computed on event yellows and named referees.
The measured referee r is below the X8 adoption threshold, so the referee
arm is dropped.

Set-play share, xG/shot, and xGOT are marked `ERA-INSUFFICIENT`: their dev
population leaves only 2025, while 2026 is virgin. No pooled 2025–2026 r is
used.

## Half shares

Goals use event first-half goals over 2021–2025. SOT, corners and shots use
available period splits over 2023–2025. Event yellows use card-event times
over 2021–2025, with the stats first-half yellow cross-check also recorded.
The JSON includes observed SD, sampling-noise subtraction, and true SD.
The five constants in `halves_constants` are presentation-only.

## Movers and primary lines

The mover check identifies clubs present in season S but absent in S−1 and
compares first-season GF/GA per match with that season's league mean. Primary
line candidates use their frozen dev windows and the standard ladders; the
closest over-rate to 0.5 is recorded in `primary_lines`.
