`analysis/MODEL_DESIGN.md` (K-IL); evidence EDA F1/F2/F3/F6.

K-IL is **not built**, by feasibility, recorded here so the absence
is an auditable decision and not an omission:

- The yellows target exists ONLY in the stats era (2025/2026+): 0 matches
  with a stats feed in 2021/2022–2024/2025, 239/240 in 2025/2026.
  There is no dev season, no warm-up season, and no scored dev window
  at all before the virgin season (2025/2026) itself.
- Trait reliability is not measurable on dev (split-half r null,
  n = 0 teams — the target is absent in every dev season), and no
  1H share is computable on dev (0 matches with FirstHalf/SecondHalf
  splits in dev), so no line can be selected and no halves constant frozen.
- The dev event feed carries no plain Yellow events at all (2021/2022–2024/2025: Red 185, YellowRed 98, Yellow 0), so there is no event-feed fallback target in dev either; the stats feed carries yellows only from 2025/2026. Referee data is likewise absent in dev (0% coverage), so no X8 referee arm exists.
- No arm, window, or line is therefore frozen, nothing is fitted,
  and the virgin is not read for yellows. The frozen split
  (dev ≤ 2024/2025, virgin 2025/2026, 2026/2027 untouched reserve) is NOT moved to
  manufacture a dev window: re-splitting after seeing the era break
  would be post-hoc window shopping. If future seasons add dev-era
  stats seasons, K-IL can be pre-registered fresh — it may not be
  rescued inside this prereg.
