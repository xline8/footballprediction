# Preprocessing — MX-ExpansionMX

Builder: `data/build_data.py` (regenerates `data/mxe_matches.csv`
and `data/mxe_team_matches.csv` from the FotMob world warehouse;
CSVs are gitignored, the builder is the committed artefact).
Extraction only — no fitting, imputation, or feature windows.

## Inclusion rules

1. Population: index rows with `league_id = 8976` (1,508 rows, all
   finished per `header.status.finished`).
2. Phase (frozen): `regular` iff `general.matchRound` is a digit
   string; all other labels are liguilla play-offs and are carried
   in the CSV with `phase=playoff` but excluded from every fit,
   score, and EDA level except the inventory counts.
3. Tournament block (frozen): from the match date — Apertura =
   15 Jun – 31 Dec of the football year's first calendar year;
   Clausura = 1 Jan – 14 Jun of the second. Block labels
   "2021/2022 - Apertura" … "2025/2026 - Clausura" (block_idx 0–9);
   "2026/2027 - Apertura" (block_idx 10) is in progress and excluded
   from the modelling corpus wholesale.
4. Modelling corpus: `finished=1 AND phase=regular AND
   block_idx<=9` → 1,208 matches. Goals corpus = all 1,208. Cards
   corpus = blocks from 2023/2024 - Apertura only (630 matches);
   2022/2023 - Clausura is excluded for partial yellow capture
   (DATA_UNDERSTANDING F2) and earlier blocks have no yellow feed.

## Field rules

- Goals: `header.status.scoreStr` is the target. HT goals are
  event-derived (goal events with `time<=45`, jleague_lib rule);
  `goals_events_complete` flags the 1 of 1,208 matches (4070356)
  where event goals ≠ header score — that row keeps its header
  target and is excluded only from halves computations.
- Cards target: unified yellows per side = event `card='Yellow'`
  plus `card='YellowRed'` (a second yellow is a yellow shown);
  `yellow_1h_*` counts the same with `time<=45`. Reds are recorded
  (direct Red + YellowRed) and never modelled as a target.
- Stats columns (`expected_goals`, `total_shots`, `ShotsOnTarget`,
  `corners`, …) are parsed from payload VALUES via flat_stats and
  are null outside 2026/2027 by construction; `has_stats_all` /
  `has_stats_half` are computed from parsed values, never from the
  index flags. Period splits are taken only where present — never
  fabricated.
- Team names canonicalised by FotMob team id (last-seen spelling);
  raw spellings kept in `home_team_raw` / `away_team_raw`.
- Referee and stadium are carried raw from matchFacts.infoBox
  (stadium city is populated on ≤2 rows per team — recorded, not
  used as a feature source).
- Sort order: (date, match_id). Kickoff UTC carried from
  `general.matchTimeUTC`.

## Defects recorded

- D1: stats/shotmap era begins only with the in-progress season
  (F1) — S/C/T not buildable.
- D2: yellow capture partial in 2022/2023 - Clausura (F2) — block
  excluded from the cards corpus.
- D3: one goal-event-incomplete match (4070356) — halves only.
- D4: the first build of this file in the builder session was
  truncated by an environment write failure; the CSV on disk is
  regenerated by running the builder and is not a committed
  artefact in this league (gitignored by repo norm).
