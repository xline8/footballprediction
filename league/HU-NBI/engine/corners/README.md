# C-HU-NBI corners engine

DEV-only copied chronological corners mechanics. HU columns are mapped to corners, total shots, possession, big chances, and box touches. Gate Zero retains the copied possession-only covariate and trailing territorial construction; plain has no covariate. Frozen line: 9.5. 2021/2022 is base and 2022/2023–2024/2025 are scored; later seasons are hard-blocked. Stats markets are FT-only.

Run `python3 run_c_obos.py`. Outputs are `results_dev.json` and per-arm `dev_predictions_gate_zero.csv` / `dev_predictions_plain.csv`.
