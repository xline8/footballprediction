# Charts

The three frozen EDA chart families (`levels_by_season.png`,
`trait_reliability.png`, `halves_constants.png`) are generated by
`../make_charts.py` from the frozen numbers in `eda_numbers.json`:

```
python3 ../make_charts.py
```

Levels and trait charts use regular-phase matches only; the halves
chart shows the first-half goal share by tournament with the frozen
pooled constant (0.4335) as the dashed line. The 2026/2027 Apertura
is partial (labelled `26/27 Ap*`).
