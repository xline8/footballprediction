# T-SE total-shots engine

Reads `data/se2_matches.csv`, uses A/B/C, and scores DEV seasons 2023–2025 after 2022 warm-up at FT ladder 19.5/20.5/21.5 (primary 20.5).

```text
python3 league/SE-Superettan/engine/total_shots/run_t_se2.py dev
```

The engine writes `results_dev.json` and `results_dev.csv`.
