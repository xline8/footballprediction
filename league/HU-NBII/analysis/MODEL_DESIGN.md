# Model design — HU-NBII

## Feasibility matrix

| candidate | target exists? | gateable dev window? | virgin read? | verdict |
|---|---|---|---|---|
| G goals | yes, 200 genuine scores | no | no | NOT BUILDABLE |
| S SOT | no, stats/shotmap empty | no | no | NOT BUILDABLE |
| C corners | no, stats/shotmap empty | no | no | NOT BUILDABLE |
| K cards | no usable target; 47 events total | no | no | NOT BUILDABLE |
| T total shots | no, shotmap empty | no | no | NOT BUILDABLE |

The program gate needs at least one training season and one season-blocked
evaluation season. There is no complete genuine season: 2025/26 is 96/240
(40%) genuine and 2026/27 is transitional with 104 matches. A within-season
round-blocked dev would change the program frame and is not run.

Goals is therefore not buildable despite a target existing. OU2.5 SE is 4.9pp
at n=104 and 3.5pp pooled at n=200, several times the 1pp clean-PASS
threshold. No fitting or engine is justified. S/C/K/T have no target source.

Rejected transfers: pooled NB-I data is a disjoint tier and has no cross-tier
play; using partial scores is contamination; and round-blocked development is
a frame change. X2 is also dropped because only three relevant movers are
identifiable and there is no gateable window.

Earliest gateable revisit: dev on 2025/26 + 2026/27 after both seasons are
complete and re-fetched with genuine scores, then virgin 2027/28. That needs a
fresh preregistration. If FotMob stats blocks appear, S/C/K/T become
re-assessable on the same revisit. Nothing is scheduled.
