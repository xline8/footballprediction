# G-FR goals engine

Reads `league/FR-Ligue2/data/fr_matches.csv`, keyed by FotMob team id. Dev is 2021/2022 warm-up plus 2022/2023–2024/2025 scoring; virgin remains conditional and is not run in Phase C. Run `python3 league/FR-Ligue2/engine/goals/run_g_engch.py dev`. Prereg: `PREREG_G_FR.md`; halves constant 0.4457. Observation is goals-only.
