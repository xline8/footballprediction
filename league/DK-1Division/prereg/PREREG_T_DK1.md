# Pre-registration — T-DK1

Frozen 2026-11-10 before fitting. Target: full-time stats-feed `total_shots_home + total_shots_away`; it exists from 2022/2023 onward and is absent in 2021/2022. Phase rule: regular rounds 1–22; feed-labelled promotion/championship and relegation rounds 23–32 are ordinary rows. Halves use frozen `total_shots_1h_share: 0.461` from 2023/2024–2025/2026. Dev is 2022/2023–2024/2025, virgin is 2025/2026 once, 2026/2027 reserved. Primary line: 26.5.

Gate Zero is the total-shots family production pattern. Permitted variants are X5 trailing target rates and X7 box touches, at most two arms. No shotmap-derived feature is eligible. Calibration: `|breach| ≤1pp` clean PASS; `≤1 SE` PROVISIONAL; otherwise FAIL. Dev gate: pooled dev LL beats climatology/base-rate and naive trailing-10; Gate Zero failure makes variants moot and virgin unread. Virgin LL must beat or tie Gate Zero and climatology, calibration must pass, and variants need the per-season sign check. Both-pass selects the lower pooled virgin LL; ties go simpler.

GATE LEGS (frozen): Dev gate — pooled dev LL and primary-line LL of an arm must beat climatology/base-rate and naive trailing-10, else the arm is dead. Virgin legs — (i) LL leg: arm's virgin LL ≤ Gate Zero's AND ≤ climatology's; (ii) calibration leg: |mean predicted − actual| ≤ 1.0pp pooled, SE reported; within 1 SE is PROVISIONAL, beyond is FAIL; (iii) variants must have LL ≤ Gate Zero in at least half of dev seasons. Both-pass rule: if Gate Zero and a variant both pass all legs, the lower pooled virgin LL ships; if only one passes, it ships; if none passes, T-DK1 FAIL and nothing ships. Virgin is read once.
