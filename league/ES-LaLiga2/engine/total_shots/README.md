# T-ES total-shots engine

Reads the ES-LaLiga2 CSV with team-id state. Arms A, B, and C use the frozen ENGCH architecture. Run `python3 league/ES-LaLiga2/engine/total_shots/run_t_engch.py dev`, then `virgin --arms A B C` for eligible arms. Prereg: `PREREG_T_ES.md`; primary line 23.5 and halves constant 0.4522.
