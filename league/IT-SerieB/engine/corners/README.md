# C-ITB corners engine

Reads the IT-SerieB CSV with team-id state. Gate Zero (X9) only —
the X7 box-touch arm was dropped in FEATURES (reliability).
Run `python3 league/IT-SerieB/engine/corners/run_c_itb.py dev`,
then `virgin --arms gate_zero`. Prereg: `PREREG_C_ITB.md`;
primary line 9.5 and halves constant 0.4734. Calibration in
results = actual − predicted.
