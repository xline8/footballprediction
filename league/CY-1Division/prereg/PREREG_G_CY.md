# Pre-registration — G-CY (Cyprus 1. Division goals)

Frozen: 2026-11-10, before any fitting. Design authority: `analysis/MODEL_DESIGN.md`; data decisions: `analysis/FEATURES.md`. Target: goals, primary OU2.5, with home-win calibration legs. Dev scored n = 776. Training seed 2021/2022; dev scored 2022/2023–2024/2025; virgin 2025/2026; confirmatory 2026/2027. All phases are ordinary matches, phase flagged, no phase feature. Calibration = actual − predicted.

Arms: Gate Zero and SHRINK. SHRINK is the only X2 cross-tier arm: no parent league is used and Cyprus 2nd division is outside the programme. The dev primary over-rate is 0.497 at OU2.5 (dev-scored window 2022/2023-2024/2025, n=776); the home-win calibration line is stated as actual minus predicted.

## GATE LEGS

Dev gate — pooled dev 1X2 LL and RPS must beat climatology, and OU2.5 LL must beat the base-rate baseline, else the arm is dead. Virgin legs — (i) LL leg: arm's virgin 1X2 LL ≤ Gate Zero's AND ≤ climatology's; (ii) calibration leg: |actual − mean predicted| ≤ 1.0pp pooled for home-win rate and for OU2.5 over-rate, SEs reported; a breach within 1 SE of the boundary is recorded PROVISIONAL PASS, beyond it FAIL; (iii) per-season sign check on dev (arm LL ≤ Gate Zero LL in at least half the dev seasons) for the both-pass rule. Both-pass rule: if Gate Zero and a variant both pass all legs, the lower pooled virgin 1X2 LL ships; if only one passes, it ships; if none passes, G-CY verdict is FAIL and nothing ships.

Mechanical reading: an arm passes iff it survives the dev gate AND passes virgin legs (i)–(ii) (PROVISIONAL counts, recorded as such) AND, for variant arms, leg (iii); Gate Zero is exempt from (iii). Ties go to the simpler arm (Gate Zero before SHRINK). If Gate Zero fails its own dev gate, variants are moot, verdict FAIL, virgin NOT read.

No fitting or engine work is part of Phase A.
