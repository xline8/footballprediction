# S-PY shots-on-target engine

Reads the PY CSV with lowercase `shotsontarget_*` fields. Seed is 2025 Apertura, dev is 2025 Clausura plus 2026 Apertura, and transitional virgin is 2026 Clausura. Arms are GZ and RS; no shotmap/XG arms are loaded.

```text
python3 league/KR-KLeague1/engine/sot/run_s_kr.py dev
python3 league/KR-KLeague1/engine/sot/run_s_kr.py virgin-metrics
```

Results are written here; virgin is deliberately unread because Gate Zero fails the 7.5 dev gate.
