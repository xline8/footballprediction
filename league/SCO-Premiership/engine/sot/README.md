# S-SCO shots-on-target engine
Reads `data/sco_matches.csv`, target `ShotsOnTarget_home + ShotsOnTarget_away`. Dev uses 2021/2022 warm-up, scores 2022/2023–2024/2025 at lines 7.5/8.5/9.5 (primary 8.5). Arms GZ, RS, X4; virgin 2025/2026 conditional on the gate. Prereg: `prereg/PREREG_S_SCO.md` (halves constant 0.4492).
Run: `python3 league/SCO-Premiership/engine/sot/run_s_sco.py dev` then `... virgin-metrics`.
