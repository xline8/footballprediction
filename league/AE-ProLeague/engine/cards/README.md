only (X8 dropped: virgin referee coverage 3.3%). TARGET = stats-feed
yellows (yellow_home/yellow_away) — the event feed carries ~0 plain
yellows in 2024/2025 and 2025/2026. Primary line 3.5.

Dev: `python3 run_k_ae.py dev`. Virgin: `python3 run_k_ae.py virgin`
(refuses if Gate Zero failed dev). Prereg: PREREG_K_AE.md.
