# T-ITB total-shots engine

Reads the IT-SerieB CSV with team-id state. Arms A (v1 pattern),
B (v2 level layer, M_bar = 25.6), C (E9 trailing-r). Tuning season
2022/2023 (lambda, r_A, layer cell chosen there only); dev gate
pool 2023/2024–2024/2025. Run
`python3 league/IT-SerieB/engine/total_shots/run_t_itb.py dev`,
then `virgin`. Prereg: `PREREG_T_ITB.md`; primary line 25.5 and
halves constant 0.4650. Calibration in results = actual −
predicted (pp).
