# S-ENGCH shots-on-target engine
Reads `data/engch_matches.csv`, target `ShotsOnTarget_home + ShotsOnTarget_away`. Dev uses 2021/2022 warm-up, scores 2022/2023–2024/2025 at lines 6.5/7.5/8.5 (primary 7.5). Arms GZ, RS, X4; virgin is reserved for later. Prereg: `PREREG_S_ENGCH.md` (halves constant 0.4548).
Run: `python3 league/ENG-Championship/engine/sot/run_s_engch.py dev` then `... virgin-metrics`.
