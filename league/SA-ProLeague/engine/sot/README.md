# S-SA shots-on-target engine
Reads `data/sa_matches.csv`, target `ShotsOnTarget_home + ShotsOnTarget_away`. Dev uses 2021/2022 and 2022/2023 as warm-up, scores 2023/2024–2024/2025 at lines 7.5/8.5/9.5 (primary 8.5). Arms GZ, RS, X4; virgin 2025/2026 conditional on the gate.
Run: `python3 league/SA-ProLeague/engine/sot/run_s_sa.py dev` then `... virgin-metrics`.
