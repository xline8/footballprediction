# T-HU-NBI total-shots engine

DEV-only copied total-shots mechanics with A/B/C arms: A ensemble, B level-adjusted ensemble, and C trailing-dispersion ensemble. HU `total_shots_h/a` are the target columns. Frozen line: 19.5. Base season is 2021/2022; 2022/2023–2024/2025 are scored; virgin seasons are hard-blocked. Stats markets are FT-only.

Run `python3 run_t_hu.py`. Outputs are `results_dev.json` and `dev_predictions_A.csv`, `dev_predictions_B.csv`, and `dev_predictions_C.csv`.
