# Phase 2 — Preprocessing: GR-SuperLeague

Builder: `league/GR-SuperLeague/data/build_data.py` (adapted from the
PL-Ekstraklasa builder; league_id 135, phase mapping added).
Outputs (gitignored, regenerated by the builder): `gr_matches.csv`
(1,261 rows, one per played match) and `gr_team_matches.csv`
(2,522 rows).

Inclusion and provenance rules:

1. Played matches only — every index row for league_id 135 is a
   played match with a score; all 1,261 are kept, ids unique
   (asserted).
2. Phase from `general.leagueName` only: `Super League` → `regular`,
   `Super League Championship Group` → `playoff_championship`,
   `Super League Conference League Group` → `playoff_conference`,
   `Super League Relegation Group` → `playoff_relegation`; any other
   value raises. Per-season phase counts are asserted against the
   format arithmetic (182 + 30 + 28 in the old format; 182 + 12 + 12
   + 30 in the new format; 2026/2027 all regular so far).
3. Period splits (FirstHalf/SecondHalf stat blocks) are carried only
   where the payload has them — never fabricated. Splits are absent
   in 2021/2022, partial in 2022/2023 (21.2%), and (near-)complete
   from 2023/2024.
4. Unified yellows: stats-feed `yellow_cards` when present, else
   event-feed Yellow counts; `cards_source` records which. Event
   counts for Yellow/YellowRed/Red are kept in their own columns for
   the cross-check.
5. Shotmap aggregates use regulation shots only (penalty-shootout
   attempts excluded); xGOT sums count only shots where
   `expectedGoalsOnTarget` is populated, with the populated count
   kept (`sm_xgot_n_*`) so era population rates are measurable.
6. Score-only payloads would be nulled rather than zero-filled;
   none occur (stats All coverage is 100% in every season), so no
   row's count target is suppressed by this rule here.
7. Season labels are the warehouse labels (`2021/2022` …
   `2026/2027`); match order is (date, match_id).
8. The 2021/2022 `total_shots` columns are carried as published but
   flagged in EDA/MODEL_DESIGN as a different measurement (feed
   artefact); they are never a scored T-GR target.
