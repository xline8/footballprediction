# C-FI corners engine

Reads `data/fi_matches.csv`, uses the possession-only territorial adjustment, warms 2021, and scores 2022–2025 at the FT ladder 8.5/9.5/10.5; primary line is 9.5. Gate Zero only.

```text
~/workspace/footballprediction/.venv/bin/python league/FI-Veikkausliiga/engine/corners/run_c_fi.py dev
```

Outputs are `results_dev.json` and `results_dev.csv`.
