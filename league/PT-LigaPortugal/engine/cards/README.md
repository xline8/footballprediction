# K-PT repair

HL-270 league yellows per team-match and K=8 shrunk for/against rates produce the model mean. X8 uses the pre-target training-window referee rate shrunk with eight matches, clamped 0.75--1.33; blank/unseen referees are exactly one. Gate Zero has no referee multiplier. NB size uses plain training-window moment variance. Complete arm/baseline rows are written to `predictions_dev.csv`.
