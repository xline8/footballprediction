# G-TH goals engine

Reads `data/th_matches.csv`; seed is 2021/2022 and DEV scores 2022/2023–2024/2025 (720 matches). Arms are Gate Zero and SHRINK. Calibration uses actual minus predicted. Outputs are `results_dev.json`, summary CSV, and `predictions_dev.csv`. Run `python3 league/TH-ThaiLeague/engine/goals/run_g_th.py dev`.
