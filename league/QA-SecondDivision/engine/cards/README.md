# K-QASD engine

Gate Zero only. The target is event-unified `yellow_home + yellow_away`
(Yellow plus YellowRed), not stats yellows. The event presentation constant
is 0.3151. The loader uses all 56 2024/2025 event rows and date-grouped
predict-then-update state; it scores 28 matches in 2025/2026 rounds 8–14.
Run `python3 run_k_qasd.py dev`. Virgin execution is not enabled by this
dev runner.
