# C-SE corners engine

Reads `data/se2_matches.csv`, uses possession-only territorial adjustment, and scores DEV seasons 2023–2025 after 2022 warm-up at FT ladder 9.5/10.5/11.5 (primary 10.5). Gate Zero only.

```text
python3 league/SE-Superettan/engine/corners/run_c_se2.py dev
```

The engine writes `results_dev.json` and `results_dev.csv`.
