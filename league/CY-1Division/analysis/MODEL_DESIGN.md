# Model design boundary

This Phase A document freezes data and preregistration only. No fitting is performed. Each market follows its Bulgarian/Russian analogue architecture, with Cyprus rows, windows, primary lines, and source decisions substituted. Goals use Gate Zero plus SHRINK; SOT uses Gate Zero plus RS with BB prior 200 versus 20,000; corners uses Gate Zero and possession-only X9; cards uses Gate Zero with the event target; total shots mirrors the BG T arms A, B, and C and its registered variants.

Every dev harness must use the 2021/2022 seed, score only 2022/2023–2024/2025, and never read virgin rows. Virgin 2025/2026 is read once only for dev-passing arms; 2026/2027 is reserved confirmatory data. Calibration is actual minus predicted. Phase is flagged but has no feature.
