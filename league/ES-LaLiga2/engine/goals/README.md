# G-ES goals engine

Reads `league/ES-LaLiga2/data/es_matches.csv`, keyed by FotMob team id. Dev is 2021/2022 warm-up plus 2022/2023–2024/2025 scoring; virgin is 2025/2026 only after the frozen preregistered gates. Run `python3 league/ES-LaLiga2/engine/goals/run_g_engch.py dev` and then `virgin-metrics`. Prereg: `PREREG_G_ES.md`; halves constant 0.4322. Observation is goals-only.
