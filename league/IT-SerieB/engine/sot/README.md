# S-ITB shots-on-target engine

Reads the IT-SerieB CSV with team-id state. Arms are Gate Zero and
RS; shotmap/xG features are not loaded (era-dead). Run
`python3 league/IT-SerieB/engine/sot/run_s_itb.py dev`, then
`virgin-metrics`. Prereg: `PREREG_S_ITB.md`; primary line 7.5 and
halves constant 0.4598. Calibration in results = actual − predicted.
