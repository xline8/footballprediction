# Pre-registration — T-EC (EC-SerieA total shots): NOT BUILT

Frozen: 2026-11-10, before any fitting. Design authority:
`analysis/MODEL_DESIGN.md` (T-EC); evidence EDA F1/F2/F3/F6.

T-EC is **not built**, by feasibility, recorded here so the absence
is an auditable decision and not an omission:

- The total-shots target exists ONLY in the stats era (2025+):
  0 matches with a stats feed in 2021–2023, 1 match in 2024,
  311/312 in 2025. There is no dev season, no warm-up season, and
  no scored dev window at all before the virgin season (2025)
  itself. This is the FI total-shots case in its strongest form:
  not a definition break within a dev window, but the complete
  absence of a dev window.
- Trait reliability is not measurable on dev (split-half r null,
  n = 0 teams), and no 1H share is computable on dev (0 matches
  with period splits in dev). No line can be selected and no halves
  constant frozen.
- No arm, window, or line is therefore frozen, nothing is fitted,
  and the virgin is not read for total shots. The frozen split is
  NOT moved to manufacture a dev window. If future seasons add
  dev-era stats seasons, T-EC can be pre-registered fresh — it may
  not be rescued inside this prereg.

Verdict: `reports/T_EC_VERDICT.md` (not-buildable).
