# J2 analysis — pointer

once for the whole J.League system; its documents live in
`league/J1/analysis/` and cover J2 explicitly throughout:

- `DATA_UNDERSTANDING.md` — coverage matrix per tier (J2: §F13 facts)
- `PREPROCESSING.md` — derivation rules for `league/J2/data/` CSVs
- `EDA.md` — findings F1–F14 with per-tier verdicts (J2 traits in F2,
  cross-tier bridge F4, feasibility F13)
- `FEATURES.md` — X1–X9 accepted / R1–R13 rejected, per-tier availability
- `MODEL_DESIGN.md` — candidate G-J2 (§2) and K-J2 (§5) are J2's designs

J2-specific artefacts produced later (charts, preregs, verdicts) live in
this league's own `league/J2/` tree (`prereg/`, `reports/`).
