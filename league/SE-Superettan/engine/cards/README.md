# K-SE cards engine

Reads event-derived unified `yellow_home`, `yellow_away` from `data/se2_matches.csv`. It warms 2021, scores 2022–2025 at 3.5, and runs Gate Zero only; referee is empty.

```text
python3 league/SE-Superettan/engine/cards/run_k_se2.py dev
```

Outputs include `results_dev.json` and `results_dev.csv`.
