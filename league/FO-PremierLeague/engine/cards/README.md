# K-FO cards engine

`run_k_fo.py dev` runs the causal chronological pass over 2021–2025, uses 2021 only for method-of-moments NB-size estimates, and scores 2022–2025. Unified yellow totals are used; the awarded/excluded match is omitted.

Gate Zero uses K=8 and SHRINK uses K=16. State assertions prove that each prediction precedes its update and that no 2026 row enters the dev harness. No virgin fit or prediction is implemented in Phase B.
