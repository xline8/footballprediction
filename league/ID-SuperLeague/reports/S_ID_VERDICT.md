# Verdict — S-ID (shots on target): **NOT BUILDABLE**

No prereg was written and nothing was fitted for this candidate,
because the feasibility condition in the programme template fails:
**the target has no valid virgin window.**

Evidence (Step 1, measured from payload content, not index flags):
`ShotsOnTarget` exists only inside the stats era — 2021/2022 from
2022-01-13 (140/306 matches), 2022/2023 complete (306/306), 2023/2024
until 2023-10-30 (153/314), 2024/2025 only 8 scattered matches — and
the virgin season 2025/2026 contains **zero** stats rows (0/306), as
does 2026/2027 (0/80). The stats feed carries no other SOT source:
the shotmap is empty in all 1,620 payloads. The warehouse index's
`has_stats` total (609) conceals the era structure entirely.

With no target in the virgin window there is no gate to run and no
virgin to read. **S-ID is NOT BUILDABLE and nothing ships.** If
FotMob restores this league's stats feed for a full recent season,
the candidate needs a fresh six-step pass over the new data; nothing
in this build pre-registers it.
