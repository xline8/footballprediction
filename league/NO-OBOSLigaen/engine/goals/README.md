# G-NO-OBOS goals engine

DEV-only expanding Dixon–Coles engine. Goals-only observations are used because all OBOS xG fields are null. Arms: GZ, SHR, X2. Primary line: OU 2.5. Only 2021–2025 are loaded; 2026 is hard-excluded. Run `python3 run_g_obos.py`; outputs are `results_dev.json` and per-match `results_dev.csv`.
