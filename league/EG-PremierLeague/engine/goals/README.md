# G-EG goals engine
Reads `data/eg_matches.csv` (league/EG-PremierLeague). Dixon-Coles port of production model_v2 (hl=270, blend 0.5; EG xG exists only from the virgin season, so every fit here is goals-only by the reference fallback). Dev: season-blocked folds scored 2022/2023, 2023/2024, 2024/2025, each fit on matches strictly before that season's first date; 2021/2022 is training seed only. Arms: gate_zero, shrink (SHRINK is mathematically inert in EG season-blocked folds: at each fold cutoff every team has 0 or >=6 prior matches — verified). Virgin 2025/2026 read once, dev-passers only (G-EG failed the dev OU2.5 leg, so the virgin was NOT read).
Run: `python3 league/EG-PremierLeague/engine/goals/run_g_eg.py dev` (virgin commands exist but must not be run for G-EG — dev gate failed).
