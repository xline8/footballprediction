# G-US-MLS goals engine

Run the development pass from the repository root:

```bash
python3 league/US-MLS/engine/goals/run_g_j1.py dev
```

Development uses US-MLS seasons 2021–2024, with OU 2.5 as the primary line and Gate Zero, SHR, and X3 arms. Virgin commands are reserved for the later stage.
