# Verdict — T-RS (RS-SuperLiga total shots): **NOT BUILT (feasibility)**

Frozen decision: PREREG_T_RS.md (branch `wip-rs-superliga`, commit
a0b379d, before any fitting).

No model was fitted, no dev gate was run, and the virgin was not read for
total shots. Reason, in one paragraph: total shots exist only in the
virgin season itself (2025/2026, 25.084/match inventory level) — the
stats feed is absent in every dev season (2021/2022–2024/2025: 0 stats
rows in 1,192 matches), so there is no dev total-shots series at all and
no dev definition check is even possible. This is the FI T-FI precedent
with zero rich-era dev seasons instead of one: FI ruled T-FI
not-buildable because the rich-era quantity existed in exactly one dev
season, which cannot support the programme's season-blocked walk-forward
dev protocol; RS has zero such seasons, so the ruling is stronger here.
This is a feasibility verdict recorded pre-fitting, not a gate FAIL. T-RS
may be pre-registered fresh once stats-era dev seasons exist; it may not
be rescued inside this prereg.
